Live protocols — ones whose token already trades — are not ranked here. They are the contrast set, not the board. A protocol listed here records no token; that is not proof it has none.

How the value is built. Implied value = TVL × 0.35, times a growth factor from the 7-day TVL change (clamped −50% to +100%, half weight), times an age factor (8% per year with no token recorded, capped at 5 years), times a chain factor (2% per distinct chain, capped at 10 chains). No name is hardcoded; the same formula recomputes every row on this page.

Board: all 40 watchlist protocols, plus the 186 below-floor pre-token protocols with the highest implied value — 226 rows. Each row carries a 7-step farm plan with costs and times.
